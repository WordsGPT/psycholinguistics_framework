# Spanish iconicity — prompts

This folder belongs to the iconicity estimation experiments. The files listed below are those present in this repository snapshot.

## Files

| File | Purpose |
|---|---|
| [`spanish_base_prompt.txt`](spanish_base_prompt.txt) | Exact Spanish instruction template used to request iconicity scores. |

The prompts are language-specific and intentionally preserve differences in the original human-rating instructions. In each case, `{WORD}` is replaced by the lexical entry.
